# 南陵九支麻将

基于 Taro + React + TypeScript 的微信小程序项目。

## 第一版

- 四人对局：1名真人玩家 + 3名电脑玩家
- 可设置总对局数：4/8/12/16局
- 仅支持自摸结算
- 庄家自摸继续连庄，并按连庄次数加分
- 闲家胡牌后庄家轮转
- 对局结束展示最终排名、总分、自摸次数、连庄胡次数、单局最高分及逐局记录

当前第一版以“人机对局流程与结算”为核心，牌桌实时摸牌、碰杠、自动判胡和完整南陵九支规则引擎将在后续版本补充。

## 开发

```bash
npm install
npm run dev:weapp
```

然后在微信开发者工具中导入项目目录，使用 `project.config.json`。

## 构建

```bash
npm run build:weapp
npm run build:h5
```
